# autok-sito

Sito statico di AutOK (IT/EN), sulla struttura del sito di SalvadApp. Nessuna build: `index.html` + `assets/` (PDF di Privacy e Termini).

- Pubblicazione: GitHub Pages dal ramo principale, cartella radice (`.nojekyll` incluso).
- L'icona dell'app e' in `assets/icon.png` e `assets/favicon.png`.
- Il link di Google Play va aggiunto quando l'app e' pubblica (oggi c'e' solo "In arrivo su Google Play").
- I PDF in `assets/` si aggiornano copiando quelli generati da `tools/legal` nel progetto dell'app.
